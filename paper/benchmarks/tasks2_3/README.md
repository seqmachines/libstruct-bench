# Tasks 2–3: oligo families and molecular workflows

The linked benchmark reconstructs T2 oligo families and T3 molecular graphs.
The [runtime inventory](protocols.json) fixes the 20-protocol native panel and source inventories;
`provenance/planning_matrix.json` preserves the earlier, broader model/harness
plan; it is not the definition of the final comparison panel. The paper's
selected trials and ten-protocol comparisons are pinned in
[`paper/provenance/`](../../provenance/), not inferred from every planned
matrix cell. The [original rules](rules.md) define the agent contract and the [network policy](network-policy.json) defines execution isolation.

## Reproduce the paper statistics

```bash
python paper/reproduce.py --statistics
```

Run from the repository root. No inference or Docker is needed. See
[`paper/README.md`](../../README.md) for the selected panels and final
Bonferroni tables. Figure 3 uses one selected attempt per protocol/system;
GPT/Codex repeats are reported separately. The final name-only comparison is
one original bundle execution versus one name-only execution, paired by protocol.
Task 2 primary macro-F1 excludes ddSEQ (`N_req=0`); Task 3 retains all protocols.

The paper's corrected scorer is explicitly imported from
`libstruct_bench.libgen.v4_7_0`; the historical `libstruct-grade-libgen` entry
point and generated historical verifier snapshots remain 4.6.0. No default
scoring behavior was changed during release cleanup.

## Generate private local tasks

Generated task directories are excluded from Git because they contain private
verifier references and source documents. Obtain approved references and lawful
source copies, verify hashes, and use the generator's documented arguments:

```bash
python -m libstruct_bench.cli.generate_libgen_tasks --help
python -m libstruct_bench.cli.plan_libgen_matrix --help
```

The generator takes local source and ground-truth roots, a protocol inventory,
and an output directory. Remote releases also take immutable repository revisions. With
`--source-delivery embedded`, source files are copied into the local Docker
build context; this is not permission to publish the task tree. With
`pinned-hf`, the historical downloader expects a source repository that may
not be publicly distributable. Do not substitute a ground-truth repository for
that source repository or use a mutable revision as a paper reference.

New agent runs require Docker, a compatible Harbor installation, and provider
credentials. They cost money and are not part of the table-reproduction command.
Authentication adapters and pinned CLI settings remain in `src/` and configs.
The GCP project identifiers in historical configs record execution provenance;
configure your own billing project for a new experiment.

`name_only/*.json` use repository-relative paths. Their generated task root and
`experiment.json` lock are local artifacts, now archived with the other private
build contexts. These configs cannot launch until those inputs are restored or
generated by the name-only preparation workflow. Existing prediction outputs
and scores have not been moved or rewritten.

`provenance/capability-training-protocols.json` retains an earlier ten-protocol
training-source inventory. The final cumulative-learning experiment uses the
58/5/10 design and historical C30 selection documented in
[`docs/improvement/`](../../../docs/improvement/README.md); do not infer that split
from the older inventory. The planner resolves the historical matrix's network
policy relative to its new location without changing its settings.
