# Paper-ready results

This directory is the paper-facing index for the NeurIPS 2026 AIDaR workshop
submission. Raw runs and canonical benchmark artifacts remain in their original
locations; the files here are derived summaries and publication assets.

## Results storyline

1. **Task 1 first:** ask whether frontier systems can reconstruct final sequencing
   libraries. On the 38 protocol--model pairs for which both interfaces returned
   a scorable result, direct APIs and coding agents were usually close, with mean
   sequence similarities of 0.755 and 0.732. Exact reconstruction remained rare:
   7/38 direct-API predictions and 8/38 coding-agent predictions were exact.
2. **Parser control second:** test whether sequence corruption during PDF-to-text
   conversion explains the Task 1 errors. Across five protocols and 80 source-visible
   nucleotide strings, human-verified text, PyMuPDF, pypdf, and Docling each
   achieved 80/80 exact recovery. MinerU OCR achieved 71/80 exact recovery,
   mean similarity 0.982, and a worst case of 0.317.
3. **Inference:** standard text-layer parsing does not explain most Task 1 failures.
   The remaining bottleneck is protocol understanding: evidence selection,
   biological abstraction, strand/orientation reasoning, target-product
   selection, and molecular assembly.

## Required caveats

- Task 1 is a preliminary analysis against the cached pre-audit benchmark labels.
  Recompute it after the frozen 40-protocol labels and configurations are ready.
- API failures were technical request failures and are excluded from paired
  accuracy comparisons. They must not be interpreted as incorrect biological
  predictions.
- The 38 paired rows repeat protocols across three model families and are not 38
  independent protocols. Pooled values are descriptive, not inferential.
- The parser control measures, for each reference string, its maximum normalized
  edit similarity to any recovered sequence. It tests sequence recovery but does
  not penalize extra parser candidates or measure downstream protocol reasoning.
- Audit schema conversions are representation work, not biological errors. Of 68
  confirmed audit findings, 31 were schema/formatting and 12 were original human
  curation errors.
